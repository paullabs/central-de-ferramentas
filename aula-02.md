# Aula 2: Como instalar qualquer projeto

Os quatro jeitos de instalar: instalador, navegador, Pinokio e IA.

## Links

- [Voicebox: baixar o instalador](https://github.com/jamiepine/voicebox/releases) · Mac com chip da Apple: dmg com arm64. Mac Intel: dmg com x64. Windows: exe com setup no nome.
- [OpenCut: abrir no navegador](https://opencut.app) · Nada para instalar.
- [Pinokio: baixar](https://pinokio.co) · Depois escolha o ComfyUI e clique em Install e Start.
- [ComfyUI](https://github.com/Comfy-Org/ComfyUI) · Cuidado com o espaço: os modelos ocupam dezenas de giga.
- [HyperFrames](https://github.com/heygen-com/hyperframes) · Para este, o jeito é pedir para a IA instalar. Veja a aula 6 para o jeito fácil.

## Para copiar e colar


**Pedido para a IA instalar (troque o link)**

```
Sou iniciante, uso Mac. Instala essa ferramenta, e faz um vídeo de dez segundos com o título do meu canal. Link: https://github.com/heygen-com/hyperframes
```

## Dicas

- Nunca baixe o Source code: ele não instala nada.
- Não sabe se o seu Mac é Apple ou Intel? Maçã no canto da tela, depois Sobre Este Mac.
- Quando a IA pedir para rodar um comando, pergunte: o que esse comando faz?
