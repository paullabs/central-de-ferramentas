# Aula 3: A Central de Ferramentas e como achar projetos

Onde ficam todos os links do curso, e como buscar outros projetos sozinho.

## Links

- **Esta Central** · A página que você está lendo. Salve nos favoritos.
- [Busca do GitHub](https://github.com/search) · Busque sempre em inglês.
- [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) · Exemplo de página em outra língua. Use Traduzir para português.

## Para copiar e colar


**Buscar uma alternativa ao CapCut**

```
capcut alternative
```

**Só projetos com mais de mil estrelas**

```
capcut alternative stars:>1000
```

**Perguntar para a IA**

```
Qual projeto grátis do GitHub faz legenda automática?
```

## Dicas

- Em Sort, escolha Most stars.
- Para guardar um projeto: Star. Para ser avisado de versão nova: Watch, Custom, só Releases, Apply.
- Não confie só na IA: abra a página e faça o teste dos trinta segundos.
