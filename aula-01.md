# Aula 1: O que é o GitHub e como ler um projeto

Você aprende a ler a página de um projeto e a saber se dá pra confiar nele.

## Links

- [Voicebox, o projeto da aula](https://github.com/jamiepine/voicebox) · Veja o README, as estrelas, a licença e o Releases.
- **Teste de confiança** · Quatro perguntas, trinta segundos: quantas estrelas, quando atualizou, quem é o dono, qual a licença.

## Dicas

- Dono certo do Voicebox: jamiepine. Existem cópias com o mesmo nome e outro dono.
- Página em inglês? Botão direito, Traduzir para português.
- Se aparecer crack, versão pro grátis ou pedido para desligar o antivírus, feche a página.
