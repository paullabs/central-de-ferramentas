# Aula 4: Editando um vídeo no OpenCut

Juntar três vídeos, cortar, deixar em pé, legendar, colocar título e exportar.

## Links

- [OpenCut: abrir o editor](https://opencut.app) · Projects, Create your first project.

## Para copiar e colar


**Atalho para cortar**

```
S
```

**Atalho para apagar o pedaço**

```
Delete
```

## Dicas

- Formato em pé: Settings, Aspect ratio, 9:16. Fundo: Background, Blur.
- Ligue o Ripple editing para não sobrar buraco depois de apagar.
- Legenda: Captions, idioma Portuguese (não deixe Auto detect), Generate transcript.
